## Recommended execution mode

**Additive first.** Import CE-MOON and GH-MOON separately after fresh preview. Stage prototypes under new experiment directories. Carry one writable lane per authority. Bounded configured Codex children may implement independent pieces under the owner; a second lane requires a deliberate authority amendment, not informal concurrent editing.

Treat `CE-ML2-BIO` and `GH-ML2-DESIGN/LEARN` as consumers or integration owners when source scopes overlap. Never reapply their original plan JSON after the existing runtime has bound gates, claims or queues.

## When supersession is preferable

If an existing implementation task would duplicate this campaign, prepare one explicit supersession transaction using the installed runtime's supported preview/reconciliation operation. Discover the current API; the package does not guess its mutation schema.

The preview must include affected tasks, successor outcomes, dependencies, active claims/dispatches, lanes and queue entries, gates/checkpoints, interfaces, and successful evidence. Finish or reconcile live work before invalidating it. Preserve completed outcomes and attach links to replacement evidence. A newer design note is not sufficient reason to delete an old numerical guarantee.

The user's authorization permits restructuring the future implementation scope; it does not justify silently discarding successful results or pretending qualification was performed. Keep an audit trail and exact source/state preconditions.

## Scope tension with ML2

The older ML2 program emphasizes choosing one scientifically justified construction and complete-cost assessment. This moonshot deliberately permits several speculative implementations and little qualification. Those are different completion standards.

Keep the experimental program separate unless an explicit amendment changes the old standard. That allows useful code to land quickly without falsifying prior promises. No benchmark win or real-data result is a prerequisite for a prototype. Correct algebra, legal access, current ownership and an honest capability report are still required.
