# Migration without losing the research

## Inventory before disposition

At activation, enumerate live authorities, accepted and pending worktrees, current source, declared interfaces, all current predecessor packages, experimental families, build targets and real consumers. Use `tools/inventory.py` as a read-only tracked-file aid; it is not a Todo service. Expand the seed `machine/preservation.json` into a separately recorded `receipts/preservation.live.json`; keep the sealed input unchanged. The seed covers 48 Baseplane cards, 13 single-cell mathematical cards, ML2, the two distinct CE moonshot campaigns, historical foundations and explicitly deferred obligations. It cannot anticipate code still being written.

For every useful behavior, record its current implementation, semantic contract, tests, evidence, consumer, destination owner and one disposition: integrated supported capability; integrated opt-in experimental capability; retained reference/negative evidence; carried unfinished outcome with a named owner/trigger; or obsolete duplicate replaced by a verified path. An experiment title is not implementation evidence. “No change required” needs inspected source and a passing consumer. A failed speed test does not justify removing the mathematical operation.

Do not take “keep everything” to mean make every old driver a public API, or keep duplicate numerical owners forever. Keep the idea, behavior and evidence. Delete accidental duplication after replacing its live uses. Immutable original bootstrap archives and raw results remain unchanged.

## Migration order

1. Freeze a small shared contract from completed predecessor code. Integrate this foundation commit before creating independent worktrees.
2. Let leaf lanes migrate/build coherent domains in disjoint source trees. Shared root CMake, central registries, shared headers and inter-project contracts have one integration owner. Leaf CMake fragments and proposed shared diffs go to that owner.
3. Integrate a minimal real vertical slice before widening APIs. CE: declared work → chosen/supplied packer → prepared native forward/derivative. BP: exact sequence → source-grounded summary → query/refinement. GH: declared observations/hypothesis → Cellerator model → fitting or evaluation → replayable scientific result.
4. Add the remaining mechanisms through those seams, then reuse them across consumers. Optional mathematical families should not turn into optional *ownership* systems.
5. Remove obsolete internal callers and redundant adapters; run installed-consumer tests and comparable end-to-end workloads. Reorganization is not accepted merely because old unit tests still pass in their old directories.

## Ownership extraction from GlassHelix

Inventory mathematics by meaning, not filename. Local hidden-state transforms, generic integrators/flows, response assembly, sparse transport, differential operators, low-rank solves, coordinate maps, regrowth primitives and tape-safe publication generally move down to Cellerator if not already there. Keep experimental interpretation, data likelihood selection, biological units, intervention semantics and acceptance criteria in GH. A small GH wrapper can preserve scientific naming without owning another kernel.

Complete the migration with two clients of the extracted primitive where useful: GH plus BP, or GH plus a standalone CE example. This is a reuse test, not a demand for artificial clients for every specialization. Avoid moving domain-specific policy just because it uses matrices.

## Publication, caches and derivatives

Every mutable derived object declares its source identities: sequence, structure, state, parameters, query and representation, as applicable. Distinguish plan reuse from result reuse. The cheap route must not retain a stale teacher, atlas, half-precision plane, directory, local Jacobian or optimizer master. Epoch publication is not necessarily expensive at every iteration: prepare immutable structure once, update generations at the relevant owner, and amortize validation.

An adaptive rewrite must deal with outstanding tapes and streams explicitly. Changing a readout, parameter order or recurrent state law is more than copying a tensor. Mutation stages must either publish a complete consistent new epoch or leave the old one valid. Host previews and reference fixtures are not a substitute for native lifetime/race tests.

Reassess its share of total preparation cost before spending heavily. Preserve older CSG1/CPE2/CPK1, compiler, native foundation, relation-update and precision work under explicit disposition. Permission-gated Ampere remains gated. Historical active labels or stale pending patches need read-only reconciliation and supported administrative repair, not a new numerical detour.

## Extension test

Before closure, a worker unfamiliar with the new implementation adds one custom packer and one new operator using the documented seam. A BP worker adds a question-specific summary/query and a GH worker creates a small experiment from installed components. Record needed edits and measure overhead against a direct native route. Fix friction discovered by this exercise. The substrate should be easier to build with than the prototype collection it replaces.
