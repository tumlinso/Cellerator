# Acceptance: usable libraries, real performance, honest scope

## Three levels, not one impossible qualification hurdle

**Reference** proves the supplied mathematical/semantic contract on focused examples. **Integrated experimental** additionally provides an installed callable route, capability rejection, tests and a real consumer. **Selected default** additionally has measured evidence for the regime in which it is selected. Preserve alternatives that are useful but not fastest. Do not require every novel model to beat a baseline before the library may express it.

Each task finishes a substantive result, not a checklist of separate build/retry/inspect tasks. Root may reduce optional exploration when a stronger integrated result is available, but must preserve omitted cards in the carry-forward ledger with a meaningful reason. Core integration cannot be declared complete by retaining everything under `experiments`.

## Required vertical slices

**Cellerator:** a supported state/update problem runs with identity or supplied layout, Cellpack where applicable, and a genuinely different strategy. The same semantic computation produces matching outputs and derivatives under declared precision. Include N=1 scalar state and actor/private-width cases; report when tensor-core arithmetic has useful width and when a direct vector path wins. Exercise a multi-step resident program, parameter updates, reuse/invalidation and one structural rewrite. Core native calls must not require Torch.

**Baseplane:** exact input with invalid bases, strand/coordinates, source spans and boundary halos builds an order-sensitive representation, answers a question from a summary, revisits exact source when needed, discovers a nonlocal group across a warp boundary, and handles an edit that changes candidate membership. Run at least one learned representation objective through the selected provider. Demonstrate that equal content at different contexts does not collapse occurrence identity. Not every consumer needs all these steps, but they must share coherent contracts.

**GlassHelix:** a declared scientific problem with explicit observations/split/hypotheses composes Cellerator mathematics, executes its learning/evaluation route, saves/replays a source-bound result, requests supported responses and retains unresolved alternatives. Preserve actual predecessor CellTag work. A supplied coordinate refactoring and a scientifically inferred mechanism must have distinct labels.

**Joint:** a bounded sequence-conditioned experiment consumes Baseplane-produced evidence/representations through an installed CE numerical route in GH. This is an interoperability witness, not a compulsory biological architecture or proof of genome-scale validity. Native numerical ownership and source provenance must survive the whole path.

## Measurement table to fill, not numbers to invent

For each comparison record commit/build, device/toolchain, precision, workload, warmup/repetitions, raw timing distribution, initialization/transfer/packing time, steady-state forward and requested derivatives, state/parameter migration, invalidation, bytes/peak workspace, kernel launches, quality/error, unsupported cases and complete-path wall time. The provided record schema requires honest `measured`, `not_run` or `unsupported` status. Empty cells are not zero time.

Separate cold one-use, warm repeated-use, changing-parameter training and changing-structure workloads. Measure representation build, global directory construction, compaction, replay/refinement and parameter/gradient traffic where relevant. Report preparation break-even, not just kernel speedup. Compare equal functions before performance; compare different model families on quality/cost fronts instead of presenting a changed model as an exact acceleration.

For small GPU operations use events or an appropriate captured repetition method and count launch overhead separately. Pin benchmark resource leases; no overlapping timing jobs. Record thermal/clock/power state when practical, and preserve vendor comparisons such as CUB, cuBLAS and cuSPARSE. Four V100s do not imply four simultaneous valid timing lanes; use the current resource authority and actual topology. Multi-GPU work is optional, not a prerequisite for proving a usable local library.

## Numerical and concurrency probes

Check gradients with finite differences in double reference arithmetic and JVP/VJP inner-product identities; then use precision-appropriate native tolerances. Include zeros with live derivatives, repeated arguments/coefficients, nonidentity axes, ragged widths, output collisions, alias rejection, stale tapes, changed weights, nonfinite inputs, capacity exhaustion, sequence seam edits and out-of-domain approximation fallbacks. Test deterministic versus declared nondeterministic reductions separately. Every derivative result is bound to the declared forward numerical convention; quantized/hardware interpolation surrogates must be identified.

For structural changes, validate state/readout equivalence when claimed, native reader/writer/event lifetimes, old tape handling, slot reincarnation and optimizer policy. For approximations, measure error and guard behavior; an instantaneous linear bound is not a trajectory guarantee. For whole-candidate inference, test that shared execution does not accidentally mix incompatible alternatives.

## Toolchain and machine scope

Target the user's Volta V100 (`sm_70`) path first. CUDA 13.0 removed offline compilation/library support for Volta; use an explicitly verified CUDA 12.x toolchain, with the already inspected 12.9 route a suitable starting point [R03]. Do not upgrade away the hardware. PTX instruction availability is target-specific: a recent PTX manual contains many instructions unavailable on SM70 [R01].

Use Volta warp collectives with valid participation and explicit synchronization, and inspect actual register/shared-memory costs [R01–R02]. No binary/INT8/TF32 Tensor Core assumption on Volta; DP4A is a distinct integer instruction path. Do not sneak in `ldmatrix`, `cp.async`, sparse MMA or Hopper warpgroup primitives. The seed CUDA helper is authored but uncompiled in the authoring environment. Existing unusual MMA seeds must be tested on SM70 rather than inferred from CPU layout tests.

## Closure is evidence, not a benchmark victory

A satisfactory result can say a new packer loses on small static data but wins on a specific high-reuse workload, or that a mathematical operator is useful while a custom kernel loses to a vendor library. Preserve that specificity. A missing external dataset, failed GPU toolchain or unimplemented derivative remains an explicit blocker for the claim that needs it—not a green checkbox satisfied by the host seed.

Human documentation leads with the scientific question and the usable path. Show selected meaningful positive or negative results with raw evidence. Agent instructions, development rationale, current status authority and historical research notes remain separate; remove tests that force permanently stale status sentences.
