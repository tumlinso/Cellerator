# Accepted architecture basis

This is a condensed design basis, not a verbatim export of the preceding conversation.

The user authorized an implementation-focused execution foundation, not an actual experiment. The agreed architecture keeps GlassHelix scientific description separate from Cellerator numerical and prepared execution, then maps results back through provenance. It requires distinct dynamical/observational/inferential roles, genuine n-ary mechanisms, shared definitions and support with independent bindings, optional derivatives, explicit activity/epoch semantics, deterministic maps/RK4 first, meaningful numerical and local ambiguity instruments, native/Python usability and independent synthetic qualification.

The detailed adopted decisions are in 01_SCOPE_AND_DECISIONS.md and 02_SCIENTIFIC_AND_NUMERICAL_CONTRACTS.md. All 35 answers are mapped to concrete tasks in machine/requirements_traceability.json. Cellerator source facts and predecessor conventions are separately identified in the source ledger. Proposed future examples are not current APIs.

Changes within this foundation are deliberately autonomous through authoritative coordination. Stable external APIs, final model choices and biological validation are not presumed. The next biological epic remains unstarted.
