# Scientific and numerical contracts

## Two linked descriptions

GlassHelix retains the scientific system and mechanism identities. Cellerator carries numerical operation meaning and the prepared execution realization. The provenance relation between them is many-to-many: a scientific mechanism may lower to several stages, and several mechanisms may fuse into one kernel. Neither a kernel boundary nor a physical sparse block identifies a biological actor.

Reuse Cellerator domain, order, geometry, partition, structure epoch and value-generation identities. Add scientific roles without building another tensor or runtime identity engine. Equal shape does not imply equal domain, order or biological meaning. State equivalence for a question does not erase individuals, multiplicities or evidence provenance.

## Roles

Dynamical state supplies the information needed by the declared transition. Inferential state summarizes evidence about possible dynamical states and mechanisms. An observation record contains values, measurement identity, time, mask and declared observation assumptions. Parameters, forcing and context are explicit bindings, not secretly concatenated state. Role interpretation can evolve; numeric capabilities must remain honest.

A reporter irrelevant to physical outcome generation can remain essential for inference. The finite-candidate fixture must preserve correlated candidate coordinates rather than keep only an insufficient marginal. A measurement can reweight candidates without retroactively modifying their biological state.

## n-ary evaluation

A mechanism instance evaluates a function of explicitly ordered/role-identified arguments, parameters and admitted context. Incidence storage does not assert pairwise biology. Repeated arguments, commutativity and output assembly ownership are declared. Never enumerate an unbounded Cartesian product merely to discover candidate interactions.

Use grouping by evaluator and useful arity/layout characteristics. An inspectable expression can compose existing relation, arithmetic and reduction operations; a precompiled custom block can provide an opaque forward implementation with honest dependency/effect/capability descriptors. Missing derivatives and unknown dependencies require conservative behavior.

## Time and updates

Every vector-field stage reads one declared state snapshot. Interactions cannot observe writes made earlier in an implementation-dependent order. Biological feedback is carried through state transition. An algebraic cycle requires an explicit solving mechanism or preparation rejection.

A direct discrete map is distinct from a vector field. RK4 is a first qualification route, not a universal solver commitment. Forcing schedules declare stage evaluation and discontinuities. The demo splits at 0.75 and uses the preceding interval's forcing to finish that interval. A parameter update is not biological time advancement.

## Derivative conventions

Expose actions rather than mandatory dense Jacobians. Each action identifies the differentiated object, input/output axes, parameter/state scales, primal generations, masks and support assumptions. Mathematical derivative at stored values is not derivative through a quantization operation. No straight-through estimator is inserted implicitly.

A first-order local null direction is not a global mechanism equivalence. Diagnostic records state singular-value tolerance, scaling, residual, context and horizon. A supplied exact identity may be stronger, but must be labeled separately from empirical numerical rank.

## Approximation

Distinguish exact transformations under declared arithmetic, justified bounded approximation, empirically assessed approximation, and unassessed behavior. Measurement noise is not a universal budget allowing arbitrary numerical error. Preserve storage quantization, arithmetic, time integration, support pruning, model ambiguity and observation uncertainty separately. Near switching or rank boundaries, escalate precision or report unresolved behavior rather than silently change a categorical answer.
