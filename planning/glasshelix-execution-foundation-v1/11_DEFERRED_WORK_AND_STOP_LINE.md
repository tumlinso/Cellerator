# Deferred work and stop line

The foundation deliberately leaves scientific questions open: whether natural excitation identifies real molecular support; when learned latents can be decomposed stably; when population observations identify useful mechanisms; how stochasticity and memory should be chosen; what licenses extrapolation; and how sequence grounds a mechanism. This epic supplies instruments for later work, not answers by architecture.

No real fibroblast dataset, TGF-beta schedule, TAC/sham cohort or laboratory validation is chosen. Synthetic fixtures are numerical and semantic correctness instruments. The later scientific epic selects data regimes, inference hypotheses, trainable quantities and biological claims.

Do not build a universal observer, arbitrary mechanism search, general sufficient-state theorem solver, exhaustive causal graph system or full optimizer framework. The finite candidate example is deliberately supplied and bounded. Null directions are local specified-map diagnostics.

Memory, stochasticity, event processes and unknown inputs remain explicit capability/role seams. Initial execution is deterministic and memoryless/augmented state. Unsupported requests fail clearly. Extra empty classes do not constitute support.

Baseplane may later attach exact sequence identity, allele/element provenance and context-dependent evidence. Record capability questions without forcing a sequence model now. CellShard is absent unless a separately justified scale requirement changes scope. No distributed work is hidden in this package.

General mutable CUDA Graph replay, cross-stream/multi-reader generality, multi-GPU execution, broad new architecture portfolios and full `.cell` compiler dependence are not required. An optional measured read-only replay route cannot hold the ordinary correct execution path hostage.

Completion is the qualified native/Python toolbox and the exact paired source revisions. The controller should stop after joint final acceptance, release owned resources, publish limitations and leave the next scientific experiment unstarted.
