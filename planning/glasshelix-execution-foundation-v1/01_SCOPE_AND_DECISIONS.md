# Scope and decisions

## Authorized objective

Build an experimental execution toolbox, not a fibroblast experiment, pretrained model, generic ML framework, or proof of biological mechanism. GlassHelix owns the scientific description, inference/observation roles, questions and interpretation. Cellerator owns reusable numerical operations, derivative execution, support/projection realizations, device resources and performance selection.

The user explicitly permits constructive changes in both repositories and replacement of the current GlassHelix workspace architecture. This permission is exercised by the later launched controller through each project's first-class task authority. This package creates no claims, worktrees or implementation. It is an inert, reviewable program.

## Decisions that define this program

The primary native path is C++20, with a thin Python binding to the same implementation. Start with deterministic state transitions, direct discrete maps and a fixed-step RK4 route. State dimension, mechanism form, observation type, question and learnable quantities are not fixed to a biological experiment. Explicit observations and a distinct inferential state must be executable, not merely documented.

Mechanisms may be general nonlinear, multi-input and multi-output. Pairwise relation application is a useful specialization, not the core biological ontology. A small inspectable composition vocabulary plus registered precompiled custom blocks is sufficient; general JIT, full language/compiler implementation and arbitrary automatic differentiation are not prerequisites.

Prepare immutable structure once and bind independent values/state. Definition reuse, support reuse, parameter tying and memoized results are different operations. Shared numerical structure never merges candidate explanations or cell identity. Maintain shared scientific submechanisms independently from how kernels are fused or partitioned.

Use persistent support plus explicit activity as the first baseline. Qualify a compact-active alternative and structural epoch replacement. Do not declare either persistent or changing topology the biological truth. A zero forward contribution may retain nonzero parameter sensitivity. Predicate exclusion is not ordinary multiplication by zero, particularly for nonfinite operands.

Provide a real general-width FP32 execution route, including width 33 and empty/tail cases where meaningful, plus an independent FP64 CPU oracle. Existing N1/N16 FP16 storage in the proven relation spine is reusable but not a permanent scientific restriction. Reduced precision, pruning and fusion require declared semantics and evidence. No native FP8 claim is made for the V100.

Expose JVP/VJP and bounded second-direction capabilities for supported smooth blocks. Unsupported derivatives fail explicitly, never as zero. Differentiate the requested vector field, discrete step, observation or implemented rollout, and record which object was differentiated. Preserve primal generations and branch decisions.

Provide local sensitivity/null-direction instruments, supplied-reduction checks, finite supplied-candidate reweighting, capability/plan inspection and replay. Do not claim exhaustive mechanism recovery, automated model discovery or global identifiability.

## Minimum useful integrated result

A separately linked native consumer describes a nonlinear n-ary system; executes prepared Cellerator operations on CPU and a real V100; evolves under supplied forcing; observes partial outputs; updates a separate finite inferential state; computes directional responses and a known null direction; changes values without rebuilding support; compares exact support realizations; and emits reproducible results with numerical and source provenance.

A prospective native demo and independent reference program are delivered. Their implementation is assigned to the epic. Neither a syntax check nor a reference-only executable counts as delivering the real consumer.

## Deliberately not built

No biological dataset acquisition, TGF-beta/TAC/sham experimental design, final learning algorithm, general Bayesian engine, universal minimal-state discovery, full DDE/SDE/stiff-solver suite, general mutable CUDA Graph runtime, distributed CellShard execution, automatic sequence interpretation or new compiler language. Keep extension contracts explicit and return unsupported when an absent capability is requested. Baseplane remains a provenance and capability-question seam.

## Decision autonomy

The controller may refine internal APIs, replace inferior abstractions, rehome useful Cellerator algorithms, split tasks, revise developmental interfaces, and transfer scopes using authoritative workflow operations. Task count and provisional path spelling are not sacred. Record rationale, update consumers and qualification, preserve unrelated work, and retain negative performance evidence. Do not ask the user to adjudicate ordinary engineering choices already within this mandate.
