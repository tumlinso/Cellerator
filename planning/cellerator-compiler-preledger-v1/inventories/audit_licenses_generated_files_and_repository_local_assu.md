# JBC license, generated-file, and repository-assumption audit

This is a read-only migration audit of CellShard commit
`b9749ad3e5146a04f847533d8c6f1a54146aed20`. The audited compiler evidence
surface contains 575 tracked files: 222 public compiler headers, 19 compiler
implementation files, 328 JBC tests, and 6 JBC benchmarks. Nothing in this
receipt authorizes copying a listed exception unchanged.

## License result

CellShard is distributed under Apache License 2.0 at `LICENSE` (Git blob
`7a4a3ea2424c09fbe48d455aed1eaa94d9124835`). No source-level SPDX or copyright
marker occurs in the 575-file audit surface, so absence of a per-file header is
not permission to omit the repository license. The current Cellerator tree has
no root `LICENSE`, `COPYING`, or `NOTICE` file. Therefore direct incorporation
of a CellShard implementation is blocked until an integration-owned licensing
decision preserves the Apache 2.0 license and any applicable notices in the
destination distribution. This inventory makes no legal compatibility claim.

## Required pre-copy gate

An applying Todo must enumerate all source blobs, run the provenance procedure,
and classify every file against JBC-X01 through JBC-X12. It fails closed if a
file is untracked, generated, from an ignored/build/install directory, missing
license resolution, governed by unreviewed instructions, or dependent on an
unmapped CellShard include/root variable. “The source compiles in CellShard” is
not evidence that it is relocatable.
