## Findings before any timing submission

1. **The programmed order differs from the frozen order.** The plan specifies `AB, BA, AB, BA, AB, BA`, with the masked control as A. `bench/chromatin_geometry/scripts/probe_packet.py:303-309` instead shuffles each pair using seed 20261103. That seed yields `BA, AB, BA, AB, BA, AB`. It remains balanced, but it is not the specified sequence. Resolve the discrepancy against the approved protocol before collecting confirmation data; it has not affected any reviewed measurement.

2. **The displayed practical-threshold flag uses unpaired arm summaries.** `bench/chromatin_geometry/scripts/probe_packet.py:705-718` calculates `practical_latency_reduction_over_5_percent` from the ratio of the two separate arm medians, although the six paired ratios are also retained. That ratio can differ from the paired median and can yield a different decision. The approved criterion requires the paired median latency gain and a paired 95% interval supporting improvement. Do not use that flag as the final decision; apply the approved paired analysis to the retained round-level pairs and the specified bootstrap. The flag alone also does not establish the interval condition.

## Follow-up: protocol corrections before capture

The two findings above are resolved in the reviewed packet source. `expected_orders()` now returns exactly AB, BA, AB, BA, AB, BA, and the timing loop uses that sequence. The decision now uses the median of the six within-round candidate/control ratios, a 10,000-draw paired bootstrap of that same estimator with seed 20261102, and requires both the greater-than-5% practical criterion and an interval entirely below ratio 1. The ratio of separate arm medians is labelled diagnostic only. The practical comparison includes a conservative `1e-12` boundary guard.

The regression tests include examples in which paired and separate-arm summaries disagree in both directions, the exact 5% boundary, and an interval that fails to support improvement. Independent execution of `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s bench/chromatin_geometry/tests -p test_probe_packet.py -v` passed all 14 tests. `pytest` was unavailable in the default Python environment; the tests ran successfully under `unittest` instead.
