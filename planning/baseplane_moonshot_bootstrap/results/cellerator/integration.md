# Cellerator moonshot numerical integration

The integrated library contains all four independently owned numerical providers: effects, tensor, learning and mechanisms. Their source-independent contracts and Baseplane consumers are listed in the [module guide](../../../../experiments/baseplane_moonshot/README.md). Baseplane interprets sequence and maps numerical outputs back to exact source; provider APIs accept numerical values and opaque caller identities. Existing ML2 and unrelated Cellerator work remain outside this integration.

## Implemented and compared

| Provider | Host comparison | Approximation or bound |
| --- | --- | --- |
| Effects | Block-affine composition against dense sequential application; explicit order witness; checkpoint reconstruction at every boundary; weighted pruning witness | Jet truncation reports error 0.0041 in its fixture; probability mass removed is accounting, not an error certificate |
| Tensor | Identity/nontrivial transforms, directed relation masks/IDs/capacity, binary path-count oracle and sampled tanh response | FP32 host inputs with double accumulation; GPU packing uses FP16; interpolation's unsampled error is fixture-specific |
| Learning | Complete objective finite differences, deterministic fits and synthetic held-out rows, exhaustive Boolean equivalence, fitted bank selection and independent stale guards | Fixed-step optimization has no convergence promise; hardening loses confidence; rewrite search is bounded |
| Mechanisms | Condensed versus full solves, scalar gradient, sparse join versus Cartesian enumeration and factorized sums, shared versus independent world outputs | Numerical linear model only; coarse P/R fixed; query equality supplies no causal claim |
