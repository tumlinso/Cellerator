Owner: `BP-MOON-060`. Suggested implementation location: `experiments/moonshot/families/rendezvous/e18`.

## Question
Can the directory itself follow the geometry of a warp?

## Concrete mechanism
Build a bulk, immutable hash table whose buckets hold a small row of keys and posting descriptors. Lanes inspect a bucket cooperatively and vote on the matching slot; overflow chains or a second hash choice retain all entries. Add concurrent updates only as a later separate variation.

## Mapping onto Volta
Coalesced bucket loads, ballot/FFS, SHFL key broadcast; global/shared atomics during bulk construction only.
