# E05 — A warp is a transition function

Owner: `BP-MOON-030`. Suggested implementation location: `experiments/moonshot/families/automata/e05`.

## Question
Can one warp represent what a region does for every possible entry state?

## Concrete mechanism
Let lane s hold T(s) for a 32-state machine. A concatenated region stores R(L(s)); fetching lane L(s) from the right table is a shuffle. Build a hierarchy of these maps, with explicit state vocabulary and reset semantics. Query a root map without traversing every base.

## Mapping onto Volta
One SHFL per scalar state-map composition; identity padding and warp-uniform execution.

## What this does not establish
Thirty-two states are a bounded model class, not a universal biological state. Table bytes must be amortized over useful regions and repeated queries.

## First small executable probe
Compose two real sequence-derived toy transition maps and compare with direct concatenation; check order and associativity.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
