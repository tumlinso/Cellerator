# E06 — Counted and witnessed transducers

Owner: `BP-MOON-030`. Suggested implementation location: `experiments/moonshot/families/automata/e06`.

## Question
Can an effect summary retain enough evidence to explain its outputs?

## Concrete mechanism
Augment each possible entry state with an emitted-count monoid and an optional first/last witness. Compose counts as cL(s)+cR(TL(s)); transform witnesses into parent coordinates. Defer full event reconstruction to a source revisit when bounded summaries cannot hold it.

## Mapping onto Volta
SHFL for state-dependent count lookup, integer add/min/max and compact witness fields.

## What this does not establish
Counts and a few witnesses do not preserve every event. Bound counter overflow; variable-length emission is not magically closed under fixed-size composition.

## First small executable probe
Two different entry states produce different counts; verify a cross-seam event can be reconstructed from source.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
