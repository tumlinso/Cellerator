# E23 — Arithmetic finite-relation composition

Numerical owner: `CE-MOON-030` in Cellerator. Sequence consumer: `BP-MOON-070` in Baseplane. Numerical implementation location: `experiments/baseplane_moonshot/families/tensor/e23`.

## Question
Can an FP16 Tensor Core tile serve as a small finite-state relation engine?

## Concrete mechanism
Encode 16-state adjacency relations as 0/1 FP16 matrices, compute ordinary FP32-accumulated products, then threshold counts to obtain existence of two-step paths. Test bounded path-count and weighted variants separately.

## Mapping onto Volta
Ordinary WMMA arithmetic followed by threshold; no native Boolean Tensor Core instruction is assumed.

## What this does not establish
For a single 16-term 0/1 product the integer range is tiny; arbitrary-length repeated counting and arbitrary semirings have different precision and algebra requirements.

## First small executable probe
Compare a known 16-state relation product to integer Boolean composition, including multiple paths and empty rows.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
