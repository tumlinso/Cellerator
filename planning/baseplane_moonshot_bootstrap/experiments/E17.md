# E17 — Whole-directory rendezvous

Owner: `BP-MOON-060`. Suggested implementation location: `experiments/moonshot/families/rendezvous/e17`.

## Question
Can distant sequence-derived objects actually find each other without oracle-assembled packets?

## Concrete mechanism
Generate keys from current carriers, build a whole-input directory by sort or count-prefix-fill, and expose complete posting ranges. Process groups larger than a warp in tiled loops. Keep coordinates and candidate reasons; separate key equality from final relation verification.

## Mapping onto Volta
CUB sort/scan as first executor; later multisplit, shared tiles and match.any for within-tile acceleration.

## What this does not establish
A global directory is not all-to-all biological reasoning. Popular keys can have quadratic pair output; tile, aggregate, budget or explicitly report truncation.

## First small executable probe
At least 97 inputs and a group of 33 equal keys, with peers crossing warp and block boundaries.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
