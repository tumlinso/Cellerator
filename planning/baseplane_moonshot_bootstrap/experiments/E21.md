# E21 — Object-by-feature Tensor Core tiles

Numerical owner: `CE-MOON-030` in Cellerator. Sequence consumer: `BP-MOON-070` in Baseplane. Numerical implementation location: `experiments/baseplane_moonshot/families/tensor/e21`.

## Question
What biologically meaningful work fills both matrix axes inside a single sequence?

## Concrete mechanism
Pack 16 promoted objects as rows and 16 local features as columns, multiply by a learned feature transform, and retain the object-to-source map. The rows come from one region or compatible event cohort, not necessarily 16 unrelated cells or genomes.

## Mapping onto Volta
WMMA m16n16k16 FP16 inputs/FP32 accumulation; explicit zero padding and opaque fragments.

## What this does not establish
Packing cost, useful occupancy and mask recovery can dominate. A 1xN vector reshaped arbitrarily is not the same operator.

## First small executable probe
Identity and a nontrivial feature transform on one 16-object tile with source IDs retained.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
