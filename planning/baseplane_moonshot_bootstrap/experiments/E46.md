# E46 — Byte dots and butterfly features

Owner: `BP-MOON-130`. Suggested implementation location: `experiments/moonshot/families/machine/e46`.

## Question
Can small floating-like mixing be replaced by structured integer/register operations where appropriate?

## Concrete mechanism
Try learned or fixed butterfly transforms for order-sensitive feature mixing, and independently try signed-byte dot products for tiny routing scores. Preserve scale/zero-point metadata and compare arithmetic meaning before combining them.

## Mapping onto Volta
SHFL.XOR butterflies, FP32/half2 arithmetic, DP4A signed packed bytes, explicit widening.

## What this does not establish
Butterflies are a restricted transform family; byte dot products are not binary tensor instructions. Quantization error and accumulator range are explicit.

## First small executable probe
Round-trip an invertible butterfly and compare one packed byte dot with its scalar sum.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
