# E24 — Tensor tiles of possible incoming states

Numerical owner: `CE-MOON-030` in Cellerator. Sequence consumer: `BP-MOON-070` in Baseplane. Numerical implementation location: `experiments/baseplane_moonshot/families/tensor/e24`.

## Question
Can dense arithmetic cheaply evaluate several possible interpretations of the same region?

## Concrete mechanism
Place 16 candidate entry-state vectors in tile rows and apply a shared local feature transform. Treat the outputs as a sampled regional response table; a later query selects/interpolates or refines the relevant state instead of re-running an expensive local block.

## Mapping onto Volta
HMMA/WMMA across possible states, not biological sample batching; shared region-conditioned parameters.

## What this does not establish
Sampling a continuous state manifold is approximate and can suffer dimension blowup. Distillation to E05 is justified only for an explicitly discretized vocabulary.

## First small executable probe
One region, several entry states and a query between sampled states; report interpolation error rather than calling it exact.
