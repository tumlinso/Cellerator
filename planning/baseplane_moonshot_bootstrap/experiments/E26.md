# E26 — Opcode-cohort wave execution

Owner: `BP-MOON-080`. Suggested implementation location: `experiments/moonshot/families/demand/e26`.

## Question
Can information choose the next operator without forcing each lane through a different branch tree?

## Concrete mechanism
Carriers contain a bounded opcode and operands. Partition them into cohorts, execute uniform operator kernels and emit the next wave. Compare ordinary kernel waves with a bounded resident CTA interpreter whose whole warp changes opcode together.

## Mapping onto Volta
Multisplit, ballot/scan, predicate selection, shared queues; resident loops bounded by epochs and explicit work budget.

## What this does not establish
Branchless is not free, and a warp-uniform branch is acceptable. No cross-block spinning queue may assume all producers are resident.
