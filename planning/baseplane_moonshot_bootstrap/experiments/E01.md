Owner: `BP-MOON-020`. Suggested implementation location: `experiments/moonshot/families/logic/e01`.

## Question
Can a learned local decision become a few truth-table instructions rather than a feature tensor?

## Concrete mechanism
Represent 32 positions per Boolean plane. Build a typed three-input gate DAG over exact bases, validity, strand and prior threshold masks; emit several planes for later learned mixing. Compile fixed truth tables into LOP3 immediates. Keep weights/truth-table provenance beside the circuit.

## Mapping onto Volta
LOP3, shifts, bitwise masks, register reuse; one lane may own 32 biological positions rather than one.

## What this does not establish
A Boolean gate cannot retain arbitrary floating magnitude. Different masks must refer to the same coordinate domain; complements are masked by validity.

## First small executable probe
Compare all eight truth-table rows and a 31/32-base seam; keep exact source coordinates.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible.
