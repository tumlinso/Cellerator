Owner: `BP-MOON-020`. Suggested implementation location: `experiments/moonshot/families/logic/e03`.

## Question
Can orientation and relative spacing be data transformations rather than duplicate branching kernels?

## Concrete mechanism
Build forward/reverse mask operators with explicit coordinate transforms. Compose spacing, adjacency, exclusions and run boundaries using cross-word funnels. Canonicalize a grammar with a strand tag, but retain both anchors when the requested duplicate policy requires them.

## Mapping onto Volta
BREV/byte permutation where appropriate, SHF-style funnels, shifts, LOP3 and adjacent coalesced loads.

## What this does not establish
Reversing two-bit fields is not the same as reversing all bits. Halos and palindrome duplicates must match existing sequence semantics.
