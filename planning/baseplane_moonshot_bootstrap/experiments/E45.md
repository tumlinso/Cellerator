# E45 — Texture-unit response tables

Owner: `BP-MOON-130`. Suggested implementation location: `experiments/moonshot/families/machine/e45`.

## Question
Can the texture hardware be a useful cheap surrogate for a small learned response surface?

## Concrete mechanism
Tabulate a two-dimensional learned response and evaluate it through an explicitly configured floating texture object. Compare nearest, interpolated and ordinary arithmetic lookup, with coordinate and boundary conventions fixed.

## Mapping onto Volta
Texture fetch/filter hardware and cache, FP coordinates; table creation remains outside the hot kernel.

## What this does not establish
Interpolation uses limited fractional precision. This is an approximate numerical path, never an exact validity or motif gate.

## First small executable probe
A bilinear function and a sharp discontinuity expose interpolation accuracy and boundary behavior.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible.
