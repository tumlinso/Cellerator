# E47 — Instruction-composition search

Owner: `BP-MOON-130`. Suggested implementation location: `experiments/moonshot/families/machine/e47`.

## Question
Can Baseplane discover a good machine idiom instead of merely selecting a library routine?

## Concrete mechanism
Enumerate bounded straight-line candidates for bit packing, rank, base permutation or state-map composition. Reject candidates by tiny exhaustive examples, compile survivors and inspect instruction count/register footprint. Preserve several alternatives without running a timing tournament now.

## Mapping onto Volta
LOP3, PRMT, SHF, BFE/BFI, IMAD, SHFL and compiler output; native SASS inspection where the toolchain supports it.

## What this does not establish
PTX mnemonics do not promise one native instruction. Correctness on small examples is not universal proof unless the entire finite input space is covered.

## First small executable probe
Synthesize two correct small bit permutations with different register/movement tradeoffs and save disassembly.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
