# E38 — Role-bound binary routing sketches

Owner: `BP-MOON-110`. Suggested implementation location: `experiments/moonshot/families/hypotheses/e38`.

## Question
Can order and role travel cheaply in a bit vector before rich floating computation?

## Concrete mechanism
Assign codes to local objects, bind role tags with XOR and position-dependent permutation, and bundle into a sketch with explicit collision risk. Use the sketch for nomination only; retain exact supports and a richer floating sidecar for final decisions.

## Mapping onto Volta
XOR, rotations/permutations, POPC distance, bit-sliced majority counters.

## What this does not establish
Bundling is lossy; XOR without role/order binding can cancel repetitions. No claim that a random binary code is a sufficient biological embedding.
