# E07 — Bounded stack grammar tiles

Owner: `BP-MOON-030`. Suggested implementation location: `experiments/moonshot/families/automata/e07`.

## Question
Can local syntax be processed as a compact register machine rather than a large token model?

## Concrete mechanism
Implement a tiny bounded push/pop transducer for nested synthetic grammar or paired sequence evidence. Store net depth, prefix underflow requirements and a short unmatched boundary stack; compose tiles when the bounded summary suffices, otherwise request detailed replay.

## Mapping onto Volta
Packed integer stack, bitfield extraction/insertion, predicates, table lookup through shuffle.

## What this does not establish
Unbounded context-free parsing is not compressed into a constant-size exact summary. Overflow is a refine/replay condition, not silent acceptance.

## First small executable probe
Construct a pair that opens before a tile boundary and closes after it, plus one depth-overflow case.

Write a scalar or algebraic fixture and the smallest representative machine path. Prefer one intelligible executable mechanism over an empty API shell. Leave alternative variants visible. Record a failed compile or unresolved semantic issue instead of hiding it or spending the whole campaign on qualification.
