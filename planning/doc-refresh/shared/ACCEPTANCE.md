# Completion checks

**Reader:** the README's first screen explains the question and approach without task IDs or acronym overload. Current status and a link to evidence are visible soon after. Follow one complete path to code/example.

**Scientific:** ambition, implemented API, tested capability and measured result remain distinct. Baseplane includes floating-point/online hierarchy; Cellerator includes the compiler and prediscovered runtime choices; GlassHelix includes useful partial inference and the intended feedback loop. Explicit state does not automatically mean known value. No universal performance or molecular-causality claim is inferred from a synthetic fixture.

**Developer:** one validated minimal build/use route; actual source paths and imports after moves; optional CUDA/host behavior described accurately per project. Three-repository consumers remain coherent. No surprise source rewrite.

**Agent:** short operational contract, managed workflow intact, no duplicate status authority, links to current design. Prior scope restrictions are reconciled by owners rather than silently bypassed.

**Evidence:** at most two selected figures per repository; methods/raw references reachable; complete relevant regimes retained; no fabricated data. Negative results explain a design decision. Any old summary is labeled historical and locally authenticated before public promotion.

**Mechanical:** scan local Markdown and source links, pending tokens and private runtime links; render all new human pages at normal and narrow widths; inspect all figures in color and grayscale; run impacted build/tests and verify source-move map. Public links to sibling repos use stable repository names; moving local paths are resolved after source work.

**Handoff:** one local receipt includes qualified HEAD, actual files/moves, tests and commands, evidence selection/omissions, unresolved issues, and next useful entry points. The cross-project coordinator compares all three receipts and shared terminology without editing another project's ledger.
