# Value and numerical profile evidence v1

Value evidence records storage/compute typing, exact value-plane and evidence
identities, observed range, zero and nonfinite rates, streaming mean/variance,
quartiles, update magnitude, dynamic range, approximation risk, and confidence.
The estimator uses allocation-free Welford moments and exact small-fixture order
statistics. These fields rank or guard candidates; observed distributions never
weaken the operation's mathematical or numerical correctness contract.
