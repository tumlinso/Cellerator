# Indexed mechanism host qualification

H01 links the actual `Cellerator::indexed_mechanism` library. Preparation copies
bounded incidence metadata and restores semantic argument/output slots from
arbitrary physical record order. Repeated source indices and repeated roles stay
separate arguments; no commutativity, pairwise factorization, or latent biological
entity is inferred. Source/destination axes retain existing persistent domain,
order, geometry and partition identities. Immutable incidence and numerical
values have independent lifetimes. Host scalar gathering is allocation-free and
checks every binding before writes; batched CUDA gather remains H03 work.

Output ownership is validated metadata at H01: duplicate destinations require the
same explicit assembly owner and initialized accumulation contracts. H01 does not
execute destination reductions or prove an actual destination initialized; those
launch bindings/assembly are later execution tasks. Unique writes may carry other
valid existing effects. Empty mechanism batches are allowed; individual
mechanisms require at least one output. Zero-argument constant evaluators remain
representable.

The H01 executable evaluates an independent noncommutative fixture from gathered
arguments, checks physical record sorting/reversal, repeated source/role retention,
metadata source lifetime, invalid slot preparation preserving prior state,
wrong-order/aliased gathering preserving sentinels, duplicate writer rejection,
and explicit shared assembly validation. No CUDA or throughput claim is made.
