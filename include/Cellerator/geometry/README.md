# Geometry

This is the canonical public home for Cellerator biological geometry
compilation: CellPack, CP-BP, support/candidate discovery contracts, semantic
geometry, packing plans, validation, and persistent execution-image geometry.

The `cellpack` C++ namespace and `CellPack::` CMake aliases remain stable during
the physical remap. They name preserved contracts and do not imply that
geometry is an optional component.

Physical projection execution and kernel candidates belong under compute.
Runtime resources belong under runtime. Planner selection belongs under
planner. CellShard owns storage and delivery, not the meanings defined here.
