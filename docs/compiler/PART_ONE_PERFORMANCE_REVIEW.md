# Part One performance and regression review

This review preserves, rather than extrapolates, the repository's source-linked
baselines. Runtime/provider comparisons remain the CE-GEO Tesla V100 `sm_70`
campaign and its strongest legal provider per regime. Generated execution is
checked against the native/compatibility matrix. Planning quality retains exact
coverage and complete-cost selection. Compiler overhead and object size use the
Part One build/toolchain identity. celleratord retains its 10 ms semantic
background-work budget and ordinary-edit responsiveness gate.

No historical result is relabeled as a fresh measurement. The direct dense
fragment/Tensor Core experiment remains explicitly non-promoted where complete
amortized cost did not beat the strongest legal baseline. Accepted changes are
the AOT compiler, cold provenance, and installed SDK metadata; none alters the
existing runtime/provider numerical baselines.
