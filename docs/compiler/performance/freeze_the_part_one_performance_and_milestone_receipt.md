# Part One performance and milestone receipt v1

The receipt aggregates twelve compiler and generated-program campaigns under
one complete-cost methodology. Each publishable result must bind source,
toolchain, hardware, profile, input, and benchmark-binary identities; include
correctness and raw samples; state its regression budget; and carry an explicit
promotion or non-promotion decision.

Contract-only, unavailable, contaminated, kernel-only, or correctness-incomplete
records are not performance evidence and are not promoted. Negative results are
retained. Any unexplained regression rejects the receipt. The progressive
milestone manifest preserves exact commands and artifacts independently of
performance promotion.
