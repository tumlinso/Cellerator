# Generated NVIDIA execution benchmark v1

On `sm_70`, generated, prelinked-provider, vendor-fallback, and legal direct-PTX
paths separately measure preparation, allocation, packing, transfer,
synchronization, launches, kernel time, canonicalization, graph replay, and
amortized reuse. Correctness and output order precede comparison. Device runs
require Project Control's exclusive accelerator lease and the repository
benchmark mutex; unavailable paths remain explicit and no host contract run is
reported as device performance.
