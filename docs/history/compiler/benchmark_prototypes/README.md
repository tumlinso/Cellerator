# Compiler benchmark prototypes

These standalone files were preserved as historical prototypes. They were not connected to the current benchmark build or measurement harness and did not produce qualified performance measurements. The active methodology checks and receipt contract live under `tests/compiler/benchmark/` and `bench/compiler/part_one_performance_receipt_v1.json`.

The archived bytes retain their original TODO-oriented filenames. See `provenance.json` for original paths, Git blob identities, and checksums.
